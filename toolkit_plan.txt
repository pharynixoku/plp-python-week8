1. TOOLS

Tool 1: Simple Calculator
This tool asks the user for two numbers and performs addition, subtraction, multiplication, or division.

Tool 2: To-Do List
This tool allows the user to add tasks, view tasks, and remove tasks from a changing list.

Tool 3: Even Number Checker
This tool asks the user for a number and checks whether the number is even or odd.

Tool 4: Name Formatter
This tool asks the user for their name and displays it in a clean and friendly format.
