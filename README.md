# PLP Python Week 8 Final Project - Personal Mini-Toolkit

## Project Description

The Personal Mini-Toolkit is a Python program that provides four simple tools through a menu-driven interface. The tools are a Simple Calculator, To-Do List, Even Number Checker, and Name Formatter. The project demonstrates variables, input/output, conditionals, loops, lists, functions, and f-strings.

## Files

### toolkit_plan.txt
Contains the plan for the Personal Mini-Toolkit, including the tools, menu, and Python concepts used.

### toolkit.py
Contains the complete working Personal Mini-Toolkit program and all four tools.

### screenshots/
Contains screenshots showing the menu, invalid choice, and each tool running.
